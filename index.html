MODUL AJAR / RANCANGAN PEMBELAJARAN

Pendekatan Deep Learning (Mindful, Meaningful, & Joyful Learning) berbasis Problem-Based Learning (PBL)

Penulis / Penyusun: Ayu Yulandari, S.Pd.
Satuan Pendidikan: SMP Negeri Informatika
Mata Pelajaran Informatika / TIK
Alokasi Waktu 2 x 45 Menit (1 Pertemuan)
Materi Utama Perangkat Keras (Hardware) & Perangkat Lunak (Software)
Model Belajar Problem-Based Learning (PBL)

I. Capaian Pembelajaran (CP)

Pada akhir fase D, peserta didik mampu mengidentifikasi komponen, fungsi, dan cara kerja komputer, perangkat keras, serta perangkat lunak pendukung dalam kehidupan sehari-hari.

II. Tujuan Pembelajaran

Melalui model pembelajaran Problem-Based Learning (PBL) dan pengamatan media interaktif, peserta didik mampu mengidentifikasi berbagai jenis perangkat keras (hardware) dan perangkat lunak (software) beserta fungsinya secara tepat, kritis, dan kolaboratif.

III. Media, Alat, dan Sumber Belajar

  • Administrasi: Absensi, Modul Ajar, & Rubrik Penilaian

  • Media Video / Link: Buka Link Media Video

Alat dan Sarana

Laptop/Komputer, Proyektor LCD, Smartphone, Jaringan Internet/Wi-Fi

B. TUGAS / AKTIVITAS KELOMPOK

1. Analisis Perangkat Keras (Hardware)

Amati komputer di lab sekolah atau ilustrasi perangkat. Sebutkan 3 perangkat input, 3 perangkat output, beserta fungsinya secara singkat!

2. Identifikasi Perangkat Lunak (Software)

Jelaskan perbedaan mendasar antara Sistem Operasi (Operating System) dan Aplikasi Pendukung, berikan masing-masing 2 contoh!

3. Studi Kasus Pemecahan Masalah (Meaningful Challenge)

Sebuah komputer di laboratorium tiba-tiba tidak bisa mengeluarkan suara saat memutar video pembelajaran. Langkah perbaikan apa saja yang akan kelompok Anda lakukan?
