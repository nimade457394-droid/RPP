Pendekatan Deep Learning (Mindful, Meaningful, & Joyful Learning) berbasis Problem-Based Learning (PBL)

Mata Pelajaran Informatika / TIK
Alokasi Waktu 2 x 45 Menit (1 Pertemuan)
Materi Utama Perangkat Keras (Hardware) & Perangkat Lunak (Software)
Model Belajar Problem-Based Learning (PBL)

I. Capaian Pembelajaran (CP)

Pada akhir fase D, peserta didik mampu mengidentifikasi komponen, fungsi, dan cara kerja komputer, perangkat keras, serta perangkat lunak pendukung dalam kehidupan sehari-hari.

II. Tujuan Pembelajaran

Melalui model pembelajaran Problem-Based Learning (PBL) dan pengamatan media interaktif, peserta didik mampu mengidentifikasi berbagai jenis perangkat keras (hardware) dan perangkat lunak (software) beserta fungsinya secara tepat, kritis, dan kolaboratif.
